### REQ-017: 计算字段配置与自动计算

**操作人员**：

| 角色 | 职责 | 参与步骤 |
|------|------|----------|
| 数据管理员 | 配置计算字段公式、验证逻辑、管理依赖 | 步骤1-5 |
| 业务人员 | 编辑档案记录触发实时重算 | 步骤7 |
| 系统 | 自动解析依赖、检测循环、触发批量/实时重算 | 步骤3-4, 6-7 |

**用户旅程**：

1. **选择计算字段分类** - 操作者: 数据管理员
   - 进入域管理→字段管理→左栏分类导航，点击"计算"分类
   - 右侧展示当前域的计算字段列表（编码/名称/公式摘要/依赖数/状态）

2. **新建计算字段** - 操作者: 数据管理员
   - 点击"新建计算字段"按钮，打开配置面板
   - 填写字段编码（英文标识）和字段名称（中文）

3. **编写公式** - 操作者: 数据管理员
   - 在公式编辑器中编写Excel风格公式
   - 通过 `{表名.字段名}` 语法引用域内基础字段/组合字段/其他计算字段
   - 系统实时语法校验，支持函数自动补全
   - 示例：`IF(AND({门店基本信息.闭店日期} <> "", NOT(ISBLANK({门店基本信息.闭店日期}))), "已闭店", {建店流程.营业状态})`

4. **系统自动解析依赖** - 操作者: 系统
   - 从公式中提取所有 `{表名.字段名}` 引用
   - 构建有向无环图（DAG）确定执行顺序
   - 检测循环依赖（A→B→A）→ 发现则阻止保存并高亮循环路径
   - 展示依赖关系列表和执行顺序编号

5. **枚举试算验证** - 操作者: 数据管理员
   - 进入试算面板，系统从各依赖字段的 distinct_values 自动填充可选参数
   - 选择单组参数手动试算，或点击"自动枚举"生成笛卡尔积批量计算
   - 结果以表格展示：参数列... → 计算结果列
   - 验证逻辑正确后，点击"确认保存"

6. **数据源同步后自动批量重算** - 操作者: 系统
   - sync-schema 完成数据拉取后，自动触发该域所有计算字段重算
   - 按 DAG 拓扑排序执行：先算无依赖的基础计算字段，再算依赖其他计算字段的
   - 重算结果写入档案记录对应字段（物化存储）
   - 异常时记录错误日志，不阻塞同步主流程

7. **记录编辑实时重算** - 操作者: 业务人员 + 系统
   - 业务人员编辑档案记录保存时，系统检测变更字段是否被计算字段依赖
   - 是则即时重算该记录的相关计算字段，结果随记录一起持久化
   - 无关字段变更不触发重算（性能优化）

**规则关注点**：

| 规则 ID | 适用步骤 | 违反处理 |
|---------|----------|----------|
| BR-017-1 | 步骤3 | 未支持函数 → 提示可用函数列表 |
| BR-017-2 | 步骤4 | 循环依赖 → 阻止保存，高亮循环链路 |
| BR-017-3 | 步骤4, 6, 7 | 被依赖字段停用 → 依赖方标记异常 |
| BR-017-4 | 步骤5 | 无去重缓存 → 提示刷新去重数据 |
| BR-017-5 | 步骤6, 7 | 计算异常 → 值置null + 记录错误 |
| BR-017-6 | 步骤6, 7 | 重算失败 → 记日志不阻塞主流程 |

**依赖锚点**：

| 域 | 依赖类型 |
|------|----------|
| modeling（基础字段/组合字段元数据） | 数据依赖 — 计算字段引用基础/组合字段 |
| modeling（字段去重值缓存 distinct_values） | 功能依赖 — 试算参数自动填充 |
| archive（sync-schema 流程） | 触发依赖 — 同步完成后触发批量重算 |
| archive（记录编辑保存） | 触发依赖 — 保存时触发实时重算 |
