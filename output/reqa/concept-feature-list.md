# 功能清单

> **优先级定义**：P0（必须有）| P1（重要但不阻塞）| P2（锦上添花）

---

## 模块一：主数据建模引擎（代号：modeling）

**职责**：提供建模工具，让数据管理员通过「建域→建表→配字段→AI分析→字段属性配置→字段映射」定义主数据模型

| 功能ID | 名称 | 描述 | 来源 | 优先级 |
|--------|------|------|------|--------|
| F-001 | 域管理 | 创建、编辑、删除主数据域，域是顶层隔离组织单元 | REQ-001 | P0 |
| F-002 | 表管理 | 在域下创建/编辑表，支持两种类型：数据源表（指向外部库）和本地数据表（系统建表） | REQ-001 | P0 |
| F-003 | 字段名称配置 | 在表中配置字段名称和基础信息，作为AI分析的输入 | REQ-001 | P0 |
| F-004 | AI字段分类与冗余检测 | AI自动将字段归入业务分组，同时检测名称相似/语义重复的字段标记为疑似冗余 | REQ-002 | P0 |
| F-005 | 分类方案管理 | 查看、编辑、重命名、合并、删除字段分类分组，拖拽调整字段归属 | REQ-002 | P1 |
| F-006 | 字段属性配置界面 | AI分类后集中配置每个字段的数据类型、枚举值、长度、必填、默认值、校验规则 | REQ-010 | P0 |
| F-007 | 字段映射配置 | 通过字段映射（本表字段→目标表字段）建立表间关系，支持联合主键映射 | REQ-001 | P0 |
| F-008 | 字段作废 | 将字段标记为已废弃（禁止物理删除），作废后档案界面隐藏、存量保留 | REQ-001 | P1 |
| F-009 | 模型文档导出 | 将域/表/字段/映射关系导出为PDF或Markdown | REQ-011 | P2 |
| F-010 | 新建档案入口 | 域列表增加「新建档案」按钮，将域的标准模型转化为档案配置 | REQ-013 | P0 |
| F-011 | 计算字段新建 | 在字段管理-计算分类下新建计算字段，填写编码/名称，编写Excel风格公式引用域内字段 | REQ-017 | P0 |
| F-012 | 公式编辑器 | Excel函数风格的公式输入（IF/CONCAT/SWITCH/IFS等），支持语法高亮、函数自动补全、字段引用选择器 | REQ-017 | P0 |
| F-013 | 依赖自动解析 | 公式保存时自动提取引用字段、构建DAG依赖图、检测循环依赖、展示执行顺序 | REQ-017 | P0 |
| F-014 | 枚举试算验证 | 保存前输入参数值跑公式看结果，支持自动笛卡尔积枚举和手动输入，参数可选项从字段去重值填充 | REQ-017 | P0 |
| F-015 | 同步后自动重算 | 数据源同步完成后按DAG顺序批量重算所有计算字段，结果物化写入档案记录 | REQ-017 | P0 |
| F-016 | 编辑实时重算 | 用户编辑保存档案记录时，检测变更字段是否被依赖，是则实时重算受影响计算字段 | REQ-017 | P0 |
| F-017 | 计算字段管理 | 计算字段列表（编码/名称/公式摘要/依赖数/状态）、编辑、停用、删除、查看依赖图 | REQ-017 | P0 |

## 模块二：档案维护中心（代号：archive）

**职责**：业务人员基于标准模型维护主数据档案，支持增删改查、同步到物理表、版本定版、操作日志

| 功能ID | 名称 | 描述 | 来源 | 优先级 |
|--------|------|------|------|--------|
| F-101 | 档案列表 | 展示所有档案，显示域名称、记录数、同步状态 | REQ-013 | P0 |
| F-102 | 档案新增 | 按字段分组展示表单，创建主数据记录（本地存储） | REQ-014 | P0 |
| F-103 | 档案编辑 | 修改档案数据，保存后生成版本快照 | REQ-014 | P0 |
| F-104 | 档案删除 | 软删除档案记录 | REQ-014 | P0 |
| F-105 | 档案详情（分组展示） | 字段按分组展示（Tab或折叠面板） | REQ-014 | P0 |
| F-106 | 同步到物理表 | 手动触发，将档案数据推送到关联的数据源物理表 | REQ-014 | P0 |
| F-107 | 同步冲突检测 | 同步前检测冲突，展示冲突列表让用户决策 | REQ-014 | P0 |
| F-108 | 同步日志 | 记录每次同步的状态、成功/失败数、详情 | REQ-014 | P1 |
| F-109 | 版本查看 | 查看记录所有历史版本（版本号、操作人、时间、变更摘要） | REQ-015 | P0 |
| F-110 | 版本定版 | 标记某版本为「已定版」，锁定不可修改 | REQ-015 | P0 |
| F-111 | 版本回滚 | 回滚到历史版本，生成新版本快照 | REQ-015 | P1 |
| F-112 | 操作日志 | 记录所有数据变更操作（谁、何时、做了什么、改了什么） | REQ-015 | P0 |
| F-113 | 同步模型变更 | 手动同步域的标准模型变更到档案 schema，先备份再应用 | REQ-016 | P1 |
| F-114 | 同步比对引擎 | 拉数时逐字段比对源值与档案值，差异不自动覆盖，生成冲突项入队 | REQ-018 | P0 |
| F-115 | 修正保护登记 | 人工编辑字段自动登记 override 标记（修正人/时间/原值），同步绝不覆盖受保护字段 | REQ-018 | P0 |
| F-116 | 冲突审查队列 | 冲突项列表（字段/档案值/源值/建议裁决），支持筛选、逐项/批量裁决「保留档案值/接受源值」 | REQ-018 | P0 |
| F-117 | 存活规则建议 | 三级规则（人工修正>源优先级>最新时间戳）在冲突项上生成建议裁决提示 | REQ-018 | P1 |
| F-118 | 字段级回写 | sync-to-source 重做为字段级两阶段：预检字段差异→勾选→仅回写勾选字段 | REQ-018 | P0 |
| F-119 | 字段级血缘 | 每个字段值记录来源（源表/人工/裁决）与更新时间，详情可查 | REQ-018 | P1 |
