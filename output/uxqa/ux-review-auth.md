### 表格字段取舍（A0 三问产出）

- **表：用户列表**　使用方：系统管理员×账号管理　任务：扫描定位+状态处置

| 字段 | 分级 | 判定理由 | 呈现形式 |
|------|------|---------|---------|
| 用户名（登录账号） | 定位键 | 靠它找到那个账号 | 靠左常显 |
| 显示名 | 定位键 | 业务称呼识别 | 紧跟用户名 |
| 角色 | 决策键 | 决定要不要改授权 | 多 Tag（并集多角色） |
| 状态 | 决策键 | 决定禁用/启用动作 | 彩色标签（启用绿/禁用红） |
| 最近登录 | 次要参考 | 偶尔看活跃度，不看也能管 | 到分精度 |
| 内部ID/密码哈希/创建时间 | 噪音 | 管理任务用不到 | 不展示 |

- **表：角色列表**　使用方：系统管理员×权限治理　任务：扫描定位+进入配置

| 字段 | 分级 | 判定理由 | 呈现形式 |
|------|------|---------|---------|
| 角色名 | 定位键 | 找到那个角色 | 靠左常显；内置管理员加「内置」Tag |
| 说明 | 次要参考 | 长文本 | 省略+tooltip |
| 用户数 | 决策键 | 删除前判断影响面 | 数字 |
| 已配置域数 | 决策键 | 一眼看出权限覆盖进度 | 如「2/3 域」 |
| 操作 | — | — | 权限 / 编辑 / 删除（≤2字动词，内置角色无删除） |

- **表：字段权限配置（抽屉内，按域切换）**　使用方：系统管理员×白名单勾选　任务：逐字段可见/可编辑决策

| 字段 | 分级 | 判定理由 | 呈现形式 |
|------|------|---------|---------|
| 字段编码 | 定位键 | 技术标识 | 靠左 |
| 字段名称 | 定位键 | 业务识别 | 紧跟编码 |
| 可见 | 决策键 | 本次配置主目标之一 | Checkbox |
| 可编辑 | 决策键 | 本次配置主目标之二 | Checkbox（未勾可见时禁用置灰——BR-019-3 可视化） |
| AI 分类分组 | — | 字段多时的扫描效率 | 分组标题行（复用域字段分组既有数据），非列 |

约束：C7 配置表字段集 = 该域释放到概念层的标准字段（与档案列表列同源接口），禁止另建字段清单接口；C8 抽屉内提供「全选可见/清空」快捷+每分组行级全选，逐条勾大域字段会崩溃。

### 反馈与容错约束（开发约束）

- C10：登录失败统一文案「用户名或密码错误」，不泄露账号是否存在；密码校验沿用 Django 既有 validators（settings.py 已配）
- C11：角色在某域零配置时，档案页该域呈现空列+a-alert 提示「当前角色未配置该域字段权限，请联系管理员」（异常路径表已登记）
- C12：禁用用户后下次请求即 401——认证层每次请求校验 is_active，禁止仅登录时校验
- C13：免登录白名单仅登录接口（+静态资源），其余全 401；对外 /api/open/（v19）走 API Key 不叠加本体系
- C14：首个 admin 账号由迁移/初始化命令创建（防上线后无人可登录），密码从环境变量读，禁止硬编码（rule §8）
- C15：写请求中不可编辑字段静默忽略（BR-019-6），复用 v19 exposed 写投影的过滤范式意识，过滤逻辑收敛单点（序列化层 helper），禁止散在各视图
