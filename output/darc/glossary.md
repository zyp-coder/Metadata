# 术语表

| 术语 | 定义 | 首次出现 |
|------|------|---------|
| 域 | 主数据管理的顶层隔离组织单元，如"供应商域"、"物料域" | reqa 概念设计 |
| 数据源表 | 指向外部数据库表的模型表，不存储数据在主数据系统 | REQ-001 |
| 本地数据表 | 直接在主数据系统数据库中创建的模型表 | REQ-001 |
| 字段映射 | 通过配置本表字段→目标表字段建立表间关系，支持联合主键 | REQ-001 |
| 字段分类 | AI将字段自动归入业务分组（如基本信息、财务信息），驱动档案分组展示 | REQ-002 |
| 冗余检测 | AI检测名称相似或语义重复的字段，标记为疑似冗余供用户确认 | REQ-002 |
| 字段属性配置 | AI分类后集中配置字段的数据类型、枚举值、长度、必填等属性 | REQ-010 |
| 档案 | 主数据的具体业务记录，如一条供应商记录 | REQ-003 |
| 版本快照 | 每次档案修改时自动保存的历史版本，可回滚 | REQ-009 |
| AI语义规则 | 用户用自然语言描述质量规则，AI转化为可执行表达式 | REQ-007 |
| 质量日报 | AI每日汇总质量检查结果生成的报告，推送企微 | REQ-008 |
| 审计日志 | 记录所有数据变更操作（谁、何时、改了什么）的可追溯日志 | REQ-012 |
| 数据源配置 | 预配置的外部数据库连接信息，表创建时可选为数据源表 | REQ-001（细化） |
| StandardField（标准字段） | 概念层一等公民，承载属性配置（type/length/enum/required/default_value），是配置源 | v7 架构重构 |
| Physical Field（物理字段） | 实现层字段，属于具体某张表，属性作为 StandardField 的同步缓存 | v7 架构重构 |
| 概念层 | StandardField 所在的抽象层，跨表统一的概念模型 | v7 架构重构 |
| 实现层 | Physical Field 所在的具体层，对应实际数据库表字段 | v7 架构重构 |
| 自动同步 | StandardField.save() 检测属性变更后批量更新所有成员 Physical Field 的机制 | v7 架构重构 |
