应用以 `src/main.ts` 为入口，通过 `createApp` 挂载 Pinia、vue-router 和 Ant Design Vue，并引入 `styles/theme.css` 进行主题定制。路由按业务域划分为 `/modeling`（建模）、`/archive`（档案）、`/settings`（设置）三大模块，均通过懒加载组件并包裹在 `layouts/MainLayout.vue` 布局中；`/login` 为独立公开页面。状态管理采用 Pinia Composition API 风格（如 `stores/modeling.ts`），HTTP 层通过 `api/index.ts` 创建带 baseURL `/api` 与拦截器的 axios 实例：请求拦截器注入 `Authorization: Token <token>`，响应拦截器统一将后端 detail/message/error 包装为 Error 对象并保留原始 response，401 时清除 token 并重定向至 `/login`。各功能模块再在 `api/archive.ts`、`api/modeling.ts`、`api/auth.ts` 中按领域拆分请求方法。类型定义集中在 `types/index.ts`，被 stores、views、components 共同引用。视图按业务域组织在 `src/views/{domain}/` 下，子组件放在对应目录的 `components/` 子文件夹中，保持模块内聚。构建流程由 `vite.config.ts` 配置别名 `@/` → `src` 及开发代理 `/api` → `http://localhost:8000`。
