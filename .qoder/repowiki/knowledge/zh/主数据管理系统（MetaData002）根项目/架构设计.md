根目录作为跨模块编排层：
- `.ai/constitution.md` 定义项目宪法（架构级决策、交互级决策、历史区），`.ai/route_index.md` 维护模块状态与依赖拓扑（modeling←archive、modeling←quality、modeling←auth、archive←auth），所有子模块开发前需遵循该契约。
- `scripts/check-all.ps1` 提供统一入口，串行执行后端 Django check/test 与前端 TypeScript/build，确保前后端同时通过。
- 前后端通过 REST API 解耦：后端 apps/modeling 与 apps/archive 各自暴露 DRF ViewSet，前端 src/api/* 按模块封装调用；字段等价组（FieldEquivalenceGroup）是 modeling→quality 的跨模块数据契约。
- 大量截图文件（*.png）与 error_output.html 作为验收证据沉淀在根目录，配合 .ai/session-details/ 会话记录形成可追溯的开发闭环。
