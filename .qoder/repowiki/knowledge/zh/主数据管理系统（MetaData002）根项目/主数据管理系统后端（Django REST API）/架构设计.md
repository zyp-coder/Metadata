项目采用标准 Django 应用结构：`config/` 为全局配置（settings、urls、wsgi），通过 `INSTALLED_APPS` 注册两个业务子应用 `apps.modeling` 和 `apps.archive`；根 URL `config/urls.py` 将 `/api/` 路由分发到各子应用的 `urls.py`。

- 分层模式：每个子应用遵循 `models → serializers → views(viewsets) → urls` 的 DRF 标准分层，业务逻辑集中在 viewset 的 action 方法中，序列化器负责输入校验与输出格式化。
- 依赖方向：`apps.archive` 通过外键引用 `apps.modeling.models.Domain`，形成 modeling → archive 的单向依赖；archive 不反向依赖 modeling 的其他模块。
- 数据存储：默认 PostgreSQL（docker-compose 提供），缓存使用 Redis（django_redis），开发环境可通过 `local_settings.py` 覆盖为 SQLite3。
- 扩展点：`tech_plugins/` 目录预留插件机制入口，`scripts/` 存放一次性迁移脚本（如 backfill_change_record_label、migrate_standard_field_attrs）。
- 部署：Dockerfile 基于 python:3.12-slim，docker-compose 编排 postgres:15 + redis:7 + backend 三服务，启动时自动执行 migrate。
