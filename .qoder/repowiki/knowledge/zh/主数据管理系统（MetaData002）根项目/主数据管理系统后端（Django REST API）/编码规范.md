- 模型类统一使用 `TextChoices` 定义枚举字段，并配套 `verbose_name`、`ordering`、`unique_together`/`indexes` 等 Meta 选项。
- ViewSet 继承自 `rest_framework.viewsets.ModelViewSet`，通过 `@action(detail=True/False, methods=[...], url_path=...)` 声明自定义端点，查询集与序列化器在类属性上声明。
- 所有字符串字段注释使用中文 `verbose_name`，JSONField 通过 `help_text` 说明数据结构格式（如 schema、lineage、details）。
- 配置项优先从环境变量读取（`os.environ.get('XXX', default)`），并通过 `local_settings.py` 的 try/except import 机制支持开发覆盖。
- 跨应用模型引用通过 `apps.get_model()` 或延迟 import 避免循环导入，保持 modeling → archive 的单向依赖。
