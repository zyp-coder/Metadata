- 路由采用 vue-router 的懒加载方式（`() => import('@/views/...')`），并为每个路由配置 `meta.title` 用于页面标题，公共页面通过 `meta.public: true` 标记以绕过鉴权守卫。
- API 调用统一通过 `src/api/index.ts` 创建的 axios 实例发起，请求拦截器自动注入 `Authorization: Token <token>`，响应拦截器将后端 detail/message/error 统一包装为 Error 对象并保留原始 response，401 时清除 token 并重定向登录页。
- Pinia store 使用 Composition API 风格（`defineStore('id', () => { ... })`），状态以 `ref` 声明并通过函数暴露 setter。
- 所有共享数据结构在 `src/types/index.ts` 中以 TypeScript interface 集中定义，并按业务域分组注释。
- 视图组件按业务域组织在 `src/views/{domain}/` 目录下，子组件放在对应目录的 `components/` 子文件夹中，保持模块内聚。
- 路径别名统一使用 `@/` 指向 `src` 根目录，避免相对路径嵌套过深。
