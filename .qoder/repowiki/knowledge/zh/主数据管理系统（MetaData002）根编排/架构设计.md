根目录承担跨子模块的编排与契约职责：.ai/constitution.md 维护架构级与交互级决策（含推翻历史），.ai/route_index.md 集中声明 modeling←archive、modeling←quality、modeling←auth、archive←auth、auth←archive 等依赖拓扑，新增模块必须同步更新；scripts/check-all.ps1 在根执行，串行调用 Django check/test（apps.modeling + apps.archive）与前端 vue-tsc/vite build，作为统一质量门禁；前后端通过 REST API 解耦，FieldEquivalenceGroup 与 ownership 是 modeling→archive→auth 的跨模块数据契约；方向性能力收敛于 archive 的 open_api_auth.py/open_api_gateway.py 与 auth 的 permission.py 三个承载点，推翻时仅替换单点；大量 *.png 截图与 error_output.html 作为验收产物沉淀在根目录，配合 .ai/session-details/ 会话记录形成可追溯的开发闭环。
