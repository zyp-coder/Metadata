本模块由三个独立的 Python 冒烟测试脚本组成，均直接调用运行中的 Django 后端（BASE=http://127.0.0.1:8000/api），不依赖 Django test client：
- smoke_auth.py：完整流程测试，覆盖未登录拦截、smoke_test 管理员登录、创建角色并配置 visible/editable 权限、创建普通用户 probe_user 并挂角色、schema 投影与记录值投影、伪造不可编辑字段被静默还原、可编辑字段正常修改、有用户时禁止删除角色、普通用户访问管理端点 403、登出后 token 失效。
- smoke_permission_overview.py：专测 GET /archives/{id}/permission-overview/ 管理员全景接口，校验返回结构（archive、field_names、apis、roles、call_stats）并对非管理员返回 403。
- smoke_src_owned.py：针对 ownership='source' 字段的边界保护，验证 PUT role permissions 拒绝将 source-owned 字段放入 editable_codes，仅 archive-owned 字段可编辑。
三者共享约定：使用 init_test_account 命令预置 smoke_test 管理员账号；通过 Authorization: Token <token> 传递 JWT；以 check(name, cond, extra) 模式收集断言结果并打印 PASS/FAIL，最终按全部通过退出码 0 报告。
